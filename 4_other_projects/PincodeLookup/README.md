# PincodeLookup

A small FastAPI service for looking up Indian postal codes (pincodes) and getting back the city, district and state. It supports single lookups and bulk lookups, with custom error handling and Pydantic validation. Built as part of the FastAPI Masterclass learning series.

## Features

- Single pincode lookup: `GET /pincode/{code}`
- Bulk lookup of up to 20 pincodes: `POST /pincode/bulk`, which also reports the pincodes that were not found
- Pincode format validation (exactly 6 digits)
- Custom exceptions with JSON error responses
- Interactive docs (Swagger UI and ReDoc) generated by FastAPI
- In-memory dataset of 12 pincodes across 10 cities, meant for demonstration

## Tech Stack

- Python 3.13+
- FastAPI (`fastapi[standard]`) and Uvicorn
- Pydantic v2 for models and validation
- [uv](https://docs.astral.sh/uv/) for dependency management (`pyproject.toml` and `uv.lock`)

## Project Structure

PincodeLookup/

├── models.py          # Pydantic request/response models and validators
├── exceptions.py      # Custom exceptions and their JSON handlers

## Getting Started

### With uv (recommended)

```bash
uv sync
uv run fastapi dev main.py
```

### With pip

```bash
python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
uvicorn main:app --reload
```

The API runs at `http://localhost:8000`.

- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

## API Reference

### `GET /`

Health/welcome check.

```json
{ "message": "Hello!" }
```

### `GET /pincode/{code}`

Returns the location for one pincode.

```bash
curl http://localhost:8000/pincode/560001
```

```json
{
  "pincode": "560001",
  "city": "Bengaluru",
  "state": "Karnataka",
  "district": "Bengaluru Urban"
}
```

Errors:

| Case | Status | `error` | Example `message` |
|------|--------|---------|-------------------|
| Not exactly 6 digits | 400 | `invalid_pincode_error` | `Pincode 12345 is in Invalid Format...` |
| Valid format, not in dataset | 404 | `pincode_not_found` | `Pincode 123456 does not exist in database...` |

```json
{
  "error": "pincode_not_found",
  "message": "Pincode 123456 does not exist in database. If you think this is an app error, contact the developers",
  "pincode": "123456"
}
```

### `POST /pincode/bulk`

Looks up several pincodes at once. Pincodes that are not in the dataset are listed under `missing` instead of raising an error.

```bash
curl -X POST http://localhost:8000/pincode/bulk \
  -H "Content-Type: application/json" \
  -d '{"pincodes": ["560001", "110001", "999999"]}'
```

```json
{
  "status": "success",
  "found": 2,
  "not_found": 1,
  "results": [
    { "pincode": "560001", "city": "Bengaluru", "state": "Karnataka", "district": "Bengaluru Urban" },
    { "pincode": "110001", "city": "New Delhi", "state": "Delhi", "district": "New Delhi" }
  ],
  "missing": ["999999"]
}
```

Validation (1 to 20 pincodes, each exactly 6 digits) is done by Pydantic and returns HTTP 422 on failure.
